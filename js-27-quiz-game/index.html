getRandomQuestion()
Uses Math.floor(Math.random() * array.length) to return a uniformly random element from an array.
getRandomComputerChoice()
Same pattern applied to the question's choices array. Each option has equal probability of selection.
getResults()
Compares computerChoice === question.answer. Returns a descriptive string — does not log, stays pure.

💡 Real-world use — random selection from arrays powers recommendation engines, A/B test variant assignment, shuffle playlists, and load balancing. The getResults() pattern — accepting data, returning a string — is how notification messages are generated in backend services.
