// Step-by-step coercion trace
    true → 1
    Boolean true coerces to 1 in numeric context. false → 0.
    null → 0
    null coerces to 0 numerically but evaluates as falsy in boolean context.
    "5" → 5
    Numeric strings coerce to numbers with the unary + or when compared with ==.
    === vs ==
    Use === always. It compares type AND value, never coerces.

    💡 Why this matters — coercion bugs are among the most common bugs in JS interviews and production code. "0 == false" is true. "'' == false" is true. Use === everywhere and you'll avoid hours of debugging.
