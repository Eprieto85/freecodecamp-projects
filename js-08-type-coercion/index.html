🎯 JavaScript Concepts

Type coercion happens when JS automatically converts one type to another. Using true + 10 gives 11 (boolean coerced to 1). "10" * 2 gives 20 (string coerced to number). null + 5 gives 5 (null coerces to 0). Fixing bugs means replacing coerced values with real numbers.
