    function getFortune() {
  const n = Math.random();       // 0 to 1
  if (n < 0.15) return "🌟 Great things ahead!";
  else if (n < 0.30) return "⚠️ Proceed with caution.";
  else if (n < 0.50) return "💡 A new idea approaches.";
  else if (n < 0.70) return "🔄 Change is coming.";
  else if (n < 0.85) return "🤝 Trust someone today.";
  else return "✨ Your moment is now.";
}
    Math.random()
    Returns [0, 1). Used to map random floats to categories with if/else if.
    if / else if
    Chained conditions check ranges in order. First truthy branch wins, rest are skipped.
    return
    Returns a value from a function. After return the function stops — no other branch runs.

    💡 Real-world use — this exact pattern (random float + if/else if ranges) powers A/B testing (20% see variant A), random content suggestions, loot drop systems in games, and traffic load balancers that route a percentage of users to different servers.
