Greeting Bot

Variables are containers for data. Every chatbot, form, and user profile starts with storing a name in a variable. Try it live.

// Enter your name and job to generate a greeting
name"Alex"
job"Developer"
greetingHello, Alex! You are a Developer.
let name = "..."
let declares a variable that CAN be reassigned. Used for values that change over time.
const job = "..."
const declares a variable that CANNOT be reassigned. Used for values that stay fixed.
"Hello, " + name
String concatenation joins values together. The + operator works for strings and numbers.

💡 Real-world use — every web app that shows "Welcome, Edisson!" is storing your name in a variable. User authentication, personalized emails, dashboard greetings — it all starts with let and const.
