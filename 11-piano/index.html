Responsive Web Design with CSS

EP · Grand Model 1988 · Bogotá

🎯 CSS Skills Demonstrated

A responsive 3-octave piano keyboard built entirely with CSS — no images, no SVGs, just code. Click any key to play!

  • position: absolute — black keys overlap white keys
  • ::after pseudo-element — black key shapes generated by CSS
  • z-index — layering black keys on top
  • @media queries — keyboard adapts to screen size
  • float + overflow — horizontal key layout
  • border-radius — rounded key tips
  • Web Audio API — real synthesized sound on click
