Record Collection

Use updateRecords() to add, update, or delete properties on a music collection. Watch the object change in real time.

// updateRecords(id, prop, value)
// change log
// recordCollection live state
delete records[id][prop]
The delete operator removes a property entirely. Called when value is an empty string — the "clear" operation.
bracket notation
records[id][prop] uses variables as keys — essential when the property name is not known at write time.
array.push(value)
When prop is "tracks" and a tracks array exists, push appends. If not, create [value] first.

💡 Real-world use — this exact function pattern — accept (record, id, prop, value), branch on the value and prop, return the mutated record — is the core of every CRUD operation in a REST API and every Redux reducer in a React app.
