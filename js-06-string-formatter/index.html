String Formatter

Paste messy user input and watch it get cleaned up. These five methods are in every form validator, search engine, and data pipeline.

// Paste any messy string to format it
.trim()
Removes spaces from both ends. Essential for form input cleaning.
.trimStart()
Removes leading whitespace only. Keeps trailing spaces.
.trimEnd()
Removes trailing whitespace only. Keeps leading spaces.
.toUpperCase()
All caps. Used for labels, error codes, and IDs.
.toLowerCase()
All lowercase. Used for email, slug, and search normalization.

💡 Real-world use — every login form calls .trim().toLowerCase() on the email before comparing. Database slugs use .toLowerCase().replace(/ /g,"-"). These methods are the first line of defense in input sanitization.
