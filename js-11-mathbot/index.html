Math.random()
Returns a float ≥ 0 and < 1. Multiply and floor to get a range.
Math.floor(x)
Rounds DOWN to the nearest integer. 4.9 → 4. Used to convert random floats to integers.
Math.ceil(x)
Rounds UP. 4.1 → 5. Useful for pagination: Math.ceil(total/perPage).
Math.round(x)
Rounds to nearest. 4.5 → 5, 4.4 → 4. Standard rounding rule.
Math.max(a, b)
Returns the largest. Used for clamping and comparison.
Math.min(a, b)
Returns the smallest. Pair with max to clamp a value in a range.

💡 Real-world use — Math.floor(Math.random() * n) is in every shuffle algorithm and random ID generator. Math.ceil(total/perPage) is on every paginated list. Math.max(0, balance) prevents negative balances in financial apps.
