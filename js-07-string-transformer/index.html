String Transformer

Replace, repeat, and chain — the string mutation toolkit. Used in template engines, data cleaners, and URL builders worldwide.

// Enter a string, what to find, and what to replace with
.replace(a, b)
Replaces only the first match. Returns a new string.
.replaceAll(a, b)
Replaces every match. The go-to for bulk substitutions.
.repeat(n)
Returns the string repeated n times. Used for padding and separators.
method.chaining()
Call multiple methods in sequence. Each returns a string the next can act on.

💡 Real-world use — URL slugs: title.toLowerCase().replaceAll(" ", "-"). Log redaction: log.replaceAll(email, "***@***"). Markdown: text.replaceAll("**", ""). These four lines cover 80% of text processing needs in real apps.
