.includes() · .slice() · Lab 05

String Inspector

Slice any string visually. See includes(), slice(start, end), and slice(-n) in action — the same methods used in search engines and content parsers.

// Enter a string and slice parameters
str.includes("x")
Returns true/false. Used in search filters, feature detection, and permission checks.
str.slice(2,5)
Extracts from index 2 up to (not including) index 5. Non-destructive — original unchanged.
str.slice(-3)
Negative index counts from the end. slice(-3) returns the last 3 characters.

💡 Real-world use — email validation uses includes("@"), preview cards use slice(0,160)+"...", file extensions use slice(-4), and URL parsers use slice(str.indexOf("/") + 1) constantly.
