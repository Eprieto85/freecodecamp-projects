Privacy Shield

Email masking protects user privacy in logs, confirmations and dashboards. Type any email to see it masked in real time.

// maskEmail(email) — live demo
input apple.pie@example.com
username apple.pie
domain @example.com
masked a*******e@example.com
// How the algorithm works
STEP 1
indexOf("@")
Find the @ position to split username from domain
STEP 2
slice(0, atIndex)
Extract the username part before the @ symbol
STEP 3
"*".repeat(n-2)
Build the asterisk middle — length minus first and last characters
STEP 4
first + *** + last
Concatenate first char + asterisks + last char + domain
// Click an example to try it

💡 Real-world use — email masking appears in confirmation pages ("We sent a code to a*****e@gmail.com"), user logs, and admin dashboards. It is built from the same string methods you use every day: .indexOf(), .slice(), and .repeat().
