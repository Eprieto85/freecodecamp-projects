Confirm Ending

Checking if a string ends with a target is used in file type validation, URL routing and input sanitization. Without .endsWith() — pure slice logic.

// confirmEnding(str, target)
true
confirmEnding("Abstraction", "action") → true
// Visual breakdown — str.slice(-target.length) === target
str (full string)
// Click an example

💡 Why not .endsWith()? — freeCodeCamp specifically bans it here to teach you that .endsWith() is just sugar for str.slice(-target.length) === target. Understanding what a built-in method does under the hood is what separates a junior from a senior developer. This exact pattern validates file extensions, URL suffixes, API versioning strings and DNS names.
