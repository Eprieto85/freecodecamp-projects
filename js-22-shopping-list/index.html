Shopping List

Array mutation methods are the foundation of every dynamic list in every app. Add items to either end, remove from either end — live.

// Array methods — try them live
// shoppingList [ ] 0 items
List is empty — add an item
.push(item)
Adds item to the END. Returns new array length.
.unshift(item)
Adds item to the START. Returns new array length.
.pop()
Removes & returns LAST item. Mutates the array.
.shift()
Removes & returns FIRST item. Mutates the array.

💡 Real-world use — these 4 methods power every dynamic list UI: cart items (push/pop), notification queues (push + shift for FIFO), undo stacks (push + pop for LIFO), playlist management and task boards. The function getShoppingListMsg(arr) demonstrates passing arrays as arguments.
