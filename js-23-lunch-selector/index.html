addLunchToEnd(arr, item)
Uses .push() — adds to the end, logs confirmation, returns updated array.
addLunchToStart(arr, item)
Uses .unshift() — adds to the start, logs confirmation, returns updated array.
removeLastLunch(arr)
Uses .pop() — removes last, handles empty array guard, returns updated array.
removeFirstLunch(arr)
Uses .shift() — removes first, handles empty array guard, returns updated array.
getRandomLunch(arr)
Math.floor(Math.random() * arr.length) — picks a random index, non-destructive.
showLunchMenu(arr)
Uses .join(", ") to display array as a comma-separated readable string.

💡 Pattern: array manager — wrapping array mutations in named functions is exactly how production apps are structured. The function is the unit of behavior, the array is the state. This pattern — functions that accept an array and return the modified array — is the foundation of reducers, state managers (Redux, Vuex), and functional programming.
