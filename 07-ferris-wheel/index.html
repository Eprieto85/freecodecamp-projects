CSS Animation — Ferris Wheel

About this project

This ferris wheel uses @keyframes CSS animations for continuous rotation. The wheel spins independently from the cabins, which counter-rotate to stay upright — simulating real physics with pure CSS.

  • 🎨 CSS @keyframes
  • ⏱ animation-duration & iteration-count
  • 🔄 Counter-rotation on cabins
  • 🌙 CSS gradient night sky
