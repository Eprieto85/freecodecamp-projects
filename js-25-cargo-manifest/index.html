validateManifest()
Checks every required property. Returns {} if valid, or an object with "Missing"/"Invalid" per failing key.
normalizeUnits()
Returns a new object with weight converted to kg (×0.45) without mutating the original. Uses spread {...obj}.
Number.isInteger()
Strict integer check — rejects floats and NaN. Paired with > 0 to validate containerId.

💡 Real-world use — this exact pattern (validate → normalize → process) is used in every logistics API, e-commerce checkout and form submission pipeline. Separating validation from business logic makes each function independently testable.
