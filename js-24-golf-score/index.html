💡 Array as lookup table — instead of returning string literals inside each if/else branch, we store them in an array and return names[index]. This pattern is called a lookup table or dictionary pattern. It is used in translation systems, state machines, scoring engines, HTTP status code maps and everywhere else a value needs to be mapped to a label.
