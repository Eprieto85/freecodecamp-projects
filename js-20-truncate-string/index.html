String Truncator

Truncation is in every product card, tweet preview, and mobile UI ever built. Type a string and set the max length to see it cut live.

// truncateString(str, num)
max length (num):
str.length 42
num 10

// Character-by-character preview
🛍️ E-Commerce
Product cards limit titles to ~40 chars to keep grid layouts consistent.
truncateString(productName, 40)
🐦 Social Media
Tweet previews, bio excerpts, and notification texts all truncate to fit.
truncateString(bio, 150)
🗂️ File Systems
File browsers shorten long path names and document titles for readability.
truncateString(path, 30)

💡 truncateString(str, num) — this two-line function (if str.length > num: return str.slice(0, num) + "...") is one of the most-used utilities in frontend development. It lives in every design system, every UI library, and every content management platform.
