🎯 CSS Skills Demonstrated

Ernesto the Penguin — built with pure CSS transforms and animations. Click him to see him wave!

  • transform: rotate() scaleX() — arms positioned and flipped with transforms
  • @keyframes animation — waddle and wave arm animations
  • border-radius — rounded shapes to build the penguin body
  • CSS variables — skin, face and beak colors via custom properties
  • linear-gradient — mountains, sky and penguin body shading
  • position: absolute — all parts stacked in a single container
  • transition — smooth wave animation on click
