Increment & Decrement

Two live counters showing prefix vs postfix behavior. The timing difference between ++x and x++ matters in loops and state management.

// Prefix — increments BEFORE returning
5
let x = 5
// Postfix — increments AFTER returning
5
let y = 5
++x (prefix)
Increments x first, then returns the new value. x is immediately updated.
x++ (postfix)
Returns the current value first, then increments. The returned value is "old".
--x (prefix)
Decrements first. Used in countdowns and reverse loops.
x-- (postfix)
Returns current, then decrements. Classic loop pattern: while(x-- > 0).

💡 Real-world use — for(let i=0; i<10; i++) is on every JS developer's screen daily. Score++ in games, pageViews++ in analytics, retries-- in error handling. The postfix form is most common in for loops; prefix matters when the incremented value is used in the same expression.
