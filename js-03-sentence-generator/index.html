Sentence Generator

Template literals inject variables directly into strings. Used in emails, notifications, reports, and every dynamic text in modern apps.

// Fill the template — ${variable} gets replaced
`Hello ${name}`
Backtick strings allow ${} expressions. Much cleaner than "Hello " + name + "!"
let x = "a";
x = "b"
Reassignment changes a let variable's value. Used for updating state over time.
${a + b}
Any JS expression works inside ${}. Math, function calls, comparisons — all valid.

💡 Real-world use — email templates, push notifications, error messages, PDF reports — every dynamic text system is a template literal at its core. `Dear ${name}, your order #${id} has shipped to ${city}.`
