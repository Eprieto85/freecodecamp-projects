🎯 CSS Skills Demonstrated

Bogotá skyline recreated using CSS variables, gradients and media queries — inspired by real Bogotá landmarks: Torres del Parque, BD Bacatá, Torre Colpatria and Monserrate.

  • CSS custom properties — all colors controlled via CSS variables for instant theme switching
  • radial-gradient / linear-gradient — sky, building textures and windows built with gradients
  • repeating-linear-gradient — building facades with repeated stripe patterns
  • clip-path: polygon() — Monserrate mountain silhouette carved with clip-path
  • @media queries — night-only silhouette mode on narrow screens
  • CSS transitions — smooth 1.4s animated day/sunset/night transitions
  • JavaScript + classList — mode switching and auto-detect by time of day
