String inspection is at the core of search engines, validators, and text processors. Type any string to analyze it live.

// Enter a string to inspect
str.length
Returns the number of characters. Used in validation, pagination, and limits.
str[0]
Bracket notation accesses a character by position (index). Zero-based.
str[str.length-1]
Last character — classic pattern used in parsing and validation.
str.indexOf("x")
Returns position of first match, or -1 if not found. Used in search features.

💡 Real-world use — str.length powers password validators ("minimum 8 chars"), str[0] is used for initials/avatars, str.indexOf() is the backbone of search highlighting and text parsing in every IDE and text editor.
