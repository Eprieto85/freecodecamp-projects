if · else · boolean conditions · Lab 10

Logic Verifier

Build boolean conditions and see which branch executes. The if/else pattern is the foundation of every decision in every program.

// Build your condition: if (a [op] b)
Quick presets:
if (cond) {}
Executes the block only when the condition is truthy.
else {}
Executes when the if condition is falsy. Always paired with if.
>, <, >=, <=
Comparison operators return true or false. The result is a boolean.
===, !==
Strict equality checks type AND value. Always prefer over == and !=.

💡 Real-world use — if (user.isLoggedIn), if (score >= passingGrade), if (stock > 0) — every business rule in every app is an if/else at its core. Knowing how to compose boolean conditions correctly is a core professional skill.
